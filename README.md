# Block

Godot 3D multiplayer sandbox game

## Premise

Block is an open-source, multiplayer, 3D game that is inspired by a variety of different online brickbuilding games (Minecraft, Blockland, legacy Roblox, Brickadia) and other games (Club Penguin, classic PC/Nintendo games, and other old Flash games). Mechanics and art direction is inspired, but not entirely adapted from their original counterparts, to make a hodge podge of a game (with the goal of it being the ultimate game I've wanted to play.) Gameplay is wholly user-directed and largely unguided, but revolves around the player's character (thoughtfully labeled as an icoguy/gal, for their icospheroid head) building and messing with objects in a Lego-like world. It has its own in-house art style and direction (created by me!) using largely self-drawn or free assets online, and there is no fundamental goal to accomplish in-game. There are, however, several main goals for Block as a game:

1. **Be an overall fun and complete game in and of itself.** This includes an optional primordial story mode, survival mechanics, built-in minigames, and more. Everything (game editor, testing, server hosting, modding, etc.) will be self-contained in one app. Everything is built with native Godot mechanics (favoring C++/native extensions, sticking to GDScript, etc.) for platform portabilityh.
2. **Provide extensibility and an open sandbox environment.** Luau scripting (reflection) and modding is planned, with all tools/gameplay mechanics being implemented in-game with user-available tooling.
3. **Allow for proper socialability and self-expression.** Character customization, chat and social features, and more are all planned and in the works.

Should these goals be reasonably fulfilled, Block will be deemed "complete" as a game, and future updates would be provided through mods and other user support. Until then, Block remains an **ACTIVE WIP**, and only a proof of concept of sorts. Expect everything to change, nothing is permanent, yadda yadda.

To that end, here is a sample of the current bucket list of features planned (listed roughly in descending order of priority):

- Character customization
- Complete UI and other core mechanics
- Proper brickbuilding and scripting
- Tooling/modding
- Simulated physics for destructible/unanchored bricks. Whole complex structures moving, etc.
- Networking/multiplayer
- Vehicle creation, destructible physics, other 3D world necessities
- Optional voxel terrain and crafting mechanics
- Mobs (for food, to heal and regain stamina) (or as companions...)
- Survival progression gamemode, minigames, etc.
- In-game CEF support for theaters! See [@dsh0416/godot-cef](https://github.com/dsh0416/godot-cef).
